# Cyber Insurance Risk Assessment System

## Project Overview

Cyber Insurance Risk Assessment System (CIRAS) is a web-based cybersecurity risk assessment platform designed to evaluate an organization's security posture and calculate cyber risk levels.

The system analyzes cybersecurity information including:

- Security practices
- Digital assets
- Vulnerabilities
- Threat information
- Business impact
- Security controls

The main goal of CIRAS is to transform cybersecurity information into measurable risk data and provide organizations with a structured risk assessment approach.

---

# Project Purpose

Traditional cyber risk assessments often depend on manual questionnaires and subjective evaluation.

CIRAS provides a structured platform where organizations can:

- Evaluate cybersecurity practices
- Analyze asset vulnerabilities
- Calculate cyber risk scores
- Identify major risk drivers
- Receive security recommendations
- Generate risk reports

# Main Features

The system evaluates organizational security practices using weighted security questions.

Assessment areas:
