# Assembly Password Verifier 🔐

## Low-Level Programming Security Project

## Project Overview

Assembly Password Verifier is a low-level programming project developed to demonstrate password authentication logic using Assembly language.

The project focuses on understanding how authentication systems work at the hardware and instruction level by implementing input handling, string comparison, and conditional verification logic.

The project demonstrates concepts including:

- Assembly programming
- User input handling
- String comparison
- Conditional logic
- Authentication verification

---

# Project Purpose

The main objectives of this project are:

- Understand low-level programming concepts
- Learn Assembly language instructions
- Implement password verification logic
- Understand memory and input handling
- Develop basic authentication functionality

# Working Principle

1. User enters a password.
2. The Assembly program stores and processes the input.
3. The entered password is compared with the stored value.
4. Conditional instructions determine authentication status.
5. The system displays the result.
