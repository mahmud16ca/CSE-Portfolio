# CPU Pipeline Simulator ⚙️

## Computer Architecture Simulation Project

## Project Overview

CPU Pipeline Simulator is a computer architecture project developed to simulate the instruction execution process inside a pipelined processor.

The project demonstrates how CPU pipelining improves instruction processing efficiency by dividing instruction execution into multiple stages.

The simulator focuses on:

- CPU instruction execution
- Pipeline stages
- Instruction flow
- Pipeline timing
- Performance analysis

---

# Project Purpose

The main objectives of this project are:

- Understand CPU pipeline architecture
- Simulate instruction execution flow
- Analyze pipeline stages and timing
- Study performance improvement through pipelining
- Understand processor execution behavior

---

# Main Features

## 1. Instruction Execution Simulation

Features:

- Simulates CPU instruction processing
- Represents instruction execution flow
- Tracks instruction movement through pipeline stages


## 2. Pipeline Stage Management

The simulator demonstrates common pipeline stages:

- Instruction Fetch (IF)
- Instruction Decode (ID)
- Execute (EX)
- Memory Access (MEM)
- Write Back (WB)


## 3. Pipeline Timing Analysis

Features:

- Displays instruction timing
- Shows pipeline execution sequence
- Analyzes processing efficiency


## 4. Performance Analysis

The system helps understand:

- Pipeline execution speed
- Instruction throughput
- Processor efficiency

1. User provides instructions as input.

3. Each instruction moves through execution stages.
4. Pipeline timing is calculated.
5. Performance information is displayed.
