# Online Quiz Platform

## Project Overview

Online Quiz Platform is a programming project developed for CSE 100 - Computational Thinking and Problem Solving.

The project demonstrates the application of computational thinking, logical reasoning, and programming fundamentals to solve a real-world problem.

---

## Technology Used

- Programming Language: C/C++
- Development Environment: Code::Blocks

---

## Project Objective

The objective of this project is to design a simple quiz-based system where users can interact with questions, provide answers, and receive results based on their performance.
